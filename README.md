# Anushree Kasturi · Portfolio

Static site (HTML/CSS/JS, no build step) hosted on GitHub Pages.

All content is plain HTML in `index.html`; images and stack icons (Simple Icons) live in `img/`. `main.js` runs Forme components ported to plain JS: Contours (background), Dot grid (header) and Dock, plus 12 VS Code themes (tokens in `style.css`), the Now tabs, the live GitHub calendar and live open-source data (what is written in `index.html` is the fallback).



Preview locally: `python3 -m http.server` → http://localhost:8000
