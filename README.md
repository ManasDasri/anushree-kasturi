# Anushree Kasturi · Portfolio

Static site (HTML/CSS/JS, no build step) hosted on GitHub Pages.

All content is plain HTML in `index.html`; project screenshots live in `img/`. `main.js` draws the dithered night scene (once, no animation), the whoami typewriter, the Now tabs, the dock highlight and the live GitHub contribution grid.



Preview locally: `python3 -m http.server` → http://localhost:8000
