# Anushree Kasturi · Portfolio

Static site (HTML/CSS/JS, no build step) hosted on GitHub Pages.

All content is plain HTML in `index.html`; project screenshots live in `img/`. `main.js` runs Forme's Contours shader (background) and Dock, ported to plain JS, plus the whoami typewriter, Now tabs and the live GitHub calendar. Open-source numbers are a snapshot; refresh them in `index.html`.



Preview locally: `python3 -m http.server` → http://localhost:8000
